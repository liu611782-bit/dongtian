# 红果鉴 / 真果鉴（添加分享与导出到相册）

基于开源项目 [Xanerix/guoapp](https://github.com/Xanerix/guoapp) 二次修改。

本版本在原有短剧 / 漫剧播放功能基础上，新增了以下能力：

- **分享本集视频**（优先分享已下载的本地文件）
- **导出到手机相册**（将已下载的视频保存到系统相册）

## 功能说明

| 功能 | 说明 |
|------|------|
| 分享 | 播放页或已下载列表中，可将当前集分享给微信、QQ 等 |
| 导出到相册 | 将已下载的视频直接保存到手机相册（新建「漫剧」相册） |
| 原有功能 | 保留原版所有站源、下载、弹幕、倍速等功能 |

> 注意：在线播放的链接通常带有时效签名，因此分享时优先使用**已下载的本地文件**。未下载的集数只能分享文字标题。
